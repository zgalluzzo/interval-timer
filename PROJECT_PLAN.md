# Interval Timer Project Plan

## Goal

Build a browser-based interval timer while practicing Git and GitHub workflows.

## Version 1 Requirements

Users can:

- Choose the number of rounds
- Set the duration of each round
- Set the rest time between rounds
- Choose an end-of-round sound
- Start the timer
- Pause and resume the timer
- Reset the timer
- See the current round
- See whether the timer is in a work or rest period
- See the remaining time

## Version 1 Constraints

- Built with HTML, CSS, and JavaScript
- Runs entirely in the browser
- Requires no account or database
- Works on desktop and mobile browsers
- Uses only properly licensed sound files

## Not Included in Version 1

- User accounts
- Cloud synchronization
- Custom uploaded sounds
- Saved workout history
- Native mobile applications
- Complex animations

## Definition of Done

Version 1 is complete when:

- All required controls work
- Work and rest periods transition correctly
- The selected sound plays at the correct time
- The timer completes the requested number of rounds
- The layout is usable on desktop and mobile
- Basic tests pass
- The site is deployed using GitHub Pages
- Setup and usage instructions appear in the README

## Possible Future Features

- Save preferred settings
- Preset workouts
- Custom sound uploads
- Full-screen mode
- Keyboard shortcuts
- Workout history
- Dark mode
